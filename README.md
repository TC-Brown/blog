# The Brown Family Blog

# Overview 

This blog project is a outlet for us to share our journey with others. We will be sharing updates, thoughts, ideas, and more. The blog will also serve as a repository for our memories and a place to connect with friends and family and others that we meet along the way.

# Tech Stack

- HTML
- CSS
- JavaScript

# Purpose

- To share our journey with others
- To connect with friends and family
- To share our memories
- To have a lightweight "Cloud" for our memories
